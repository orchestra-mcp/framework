## Architecture

**Plugin System (38 plugins)**:
- **4 core** (in-process): storage.markdown, tools.features, tools.marketplace, transport.stdio
- **34 optional** (QUIC + mTLS): AI bridges, devtools, agent orchestrator, services, integrations

**In-Process Router** (`libs/cli/internal/inprocess/`):
- InProcessRouter — direct Go function calls for core plugins
- TCPServer (port 50101) — length-delimited Protobuf for desktop apps
- ExternalPlugin — QUIC connections for optional plugins

**Database Strategy** (moving toward):
- PostgreSQL (cloud) — source of truth, pgvector, JSONB, tsvector
- SQLite (local) — offline MCP storage, replacing Markdown files
- Redis — real-time pub/sub for sync

2. **Sync system**: Version vectors, conflict resolution, real-time WebSocket
3. **Claude Code bridge**: Tunnel-based smart actions between web dashboard and desktop MCP
4. **Team features**: Shared projects, activity feeds, connected tunnels
5. **RAG integration**: SQLite-backed context awareness via engine-rag
