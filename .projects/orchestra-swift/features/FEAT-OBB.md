# Shared components (StatusBadge, ConnectionIndicator, EmptyStateView)

StatusBadge: workflow state pill with color-coded background and label. ConnectionIndicator: green/yellow/red dot with label (Connected/Reconnecting/Disconnected). EmptyStateView: centered icon + title + subtitle + optional action button. These are reused across all plugins.
