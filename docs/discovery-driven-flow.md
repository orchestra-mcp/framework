# Discovery-Driven Outcome Flow

> This methodology is now delivered as an installable pack rather than hardcoded MCP tools.

## Where to find it

The discovery flow is implemented in [`packs/pack-flow/`](../packs/pack-flow/) as a set of skills (markdown-based instructions) that manage flow state using local `.flow/` files.

Install it with:

```bash
orchestra pack install orchestra-mcp/pack-flow
```

See the pack's [README](../packs/pack-flow/README.md) for full documentation on the three operating modes (Discovery, Outcome, Scale), hypothesis-driven cycles, experiments, and review workflows.
