# Pomodoro standalone floating desktop widget with countdown

Create a floating pomodoro widget for Flutter desktop. (1) Small always-on-top window showing: timer countdown (MM:SS), current phase (work/break), session count. (2) Controls: start/pause/skip/reset. (3) Minimize to tiny pill showing just the timer. (4) Integrates with existing PomodoroManager and PomodoroSession PowerSync table. (5) Launches from system tray menu or pomodoro tab. (6) Desktop only (macOS/Windows/Linux).
