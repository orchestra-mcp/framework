# Rich Post Embeds & Link Previews

Enhance the PostEmbed component to support native social media embeds (Twitter/X, Instagram, Facebook), additional video platforms (TikTok, Loom, Wistia), improved image detection for URLs without file extensions, and rich link preview cards with Open Graph metadata fetched via a Go API endpoint.
