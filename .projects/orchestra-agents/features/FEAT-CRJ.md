# Workflow sharing across team/public with project include system

Skills/Agents/Hooks with scope=public get a shareable URL. Any team member can browse and include public skills into their projects via the project include API. Included items show in the project sidebar. When a skill is updated, all projects that include it get the update on next sync. Web UI: browse marketplace of public skills/agents, one-click include into project.
