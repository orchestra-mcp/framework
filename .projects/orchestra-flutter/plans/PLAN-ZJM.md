# Terminal Emulator with Tunnel Session Sharing

Full terminal emulator in the Flutter app with three session types (Terminal/SSH/Claude) and tunnel connectivity from web/mobile to the desktop app. Includes Go backend streaming changes, interactive SSH sessions, Flutter xterm UI, MCP JSON-RPC client layer, and router/shell integration.
