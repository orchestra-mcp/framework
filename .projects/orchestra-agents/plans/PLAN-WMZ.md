# Full MCP Compatibility for Claude Code Desktop App

Update Orchestra MCP to fully support Claude Code Desktop App and MCPB bundle format. Includes: protocol version update (2024-11-05 → 2025-06-18), resources capability (resources/list, resources/read), logging capability (logging/setLevel, notifications/message), listChanged notifications for dynamic tool updates, MCPB bundle packaging for one-click install in Claude Desktop, and Claude Desktop config generation support.
