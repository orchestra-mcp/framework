# Public project sharing with read-only web views

Projects can be marked as public by the team owner. Public projects get a shareable URL showing: project health, feature board (kanban), burndown chart, team members, recent activity. No auth required for viewing. SEO-friendly server-rendered pages. Useful for open-source projects sharing their roadmap. Toggle in project settings: Public/Private.
