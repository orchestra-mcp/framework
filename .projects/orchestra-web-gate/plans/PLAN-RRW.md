# Full RTL & Multi-Language Support (AR/EN)

Add complete RTL and multi-language support to the Next.js frontend. Uses next-intl with dual routing: URL-based (/en/, /ar/) for marketing pages (SEO), preference-based for dashboard. Covers ~800 strings, ~67 directional CSS conversions, ~34 icon flips, Arabic font integration.
