# Project manager web interface (assign, track, report across teams)

Full PM dashboard on web: assign features to team members (drag-drop or dropdown), track progress across all team projects, generate sprint reports, velocity charts, workload distribution. Kanban board view per project. Gantt-style timeline view across projects. Export reports as PDF. This is the culmination of the web-as-source-of-truth architecture where PMs manage everything from web, agents execute on desktop via tunnel bridge.
