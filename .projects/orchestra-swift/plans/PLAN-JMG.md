# Swift macOS Chat UX Overhaul — 15 Features

Complete overhaul of the Swift macOS chat experience with 15 features: tool result cards, model/mode selectors, voice TTS/STT, @ file listing from workspace, / agent autocomplete, session metadata status bar, persistent chat sessions, list selection fix, permission system, AskUserQuestion UI, screenshot helper, file drag-drop/paste input, browser awareness UI, thinking mode toggle, and configurable loading words.
