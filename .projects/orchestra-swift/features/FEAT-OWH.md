# NotesPlugin (built-in plugin with notes list + editor)

NotesPlugin: OrchestraPlugin conformance, id "notes", icon "note.text", section .sidebar, order 3. NotesView: sidebar with search, new note, pinned section, note items (icon, title, preview, tags, date). NoteEditor: toolbar (pin, save, delete), title input, tags bar, markdown content editor.
