# Orchestra MCP — Complete Capabilities Overview

## 🎯 What Is Orchestra MCP?

Orchestra MCP is an **AI-powered project management and development framework** that runs as an MCP (Model Context Protocol) server. It provides **290+ tools and 5 prompts** across 36 plugins, turning your AI coding assistant into a full-stack development platform with enforced workflows, gated quality checks, and multi-agent orchestration.

---

## 🔧 Core Capabilities

### 1. Feature-Driven Workflow Management (tools.features — 34 tools)
- **Create, track, and advance features** through a gated lifecycle: `todo → in-progress → in-testing → in-docs → in-review → done`
- **Feature kinds**: feature, bug, hotfix, chore, testcase
- **Enforced gates** with evidence requirements (code complete, test complete, docs complete)
- **Session-scoped locking** prevents concurrent modification conflicts
- **Plan-first for large tasks**: create plans, break them into features with dependencies
- **Request queue**: queue incoming work, convert to features when ready
- **Bug reporting** with cross-references to original features

### 2. Multi-Agent Orchestration (agent.orchestrator — 20 tools)
- **Define agents** with specific roles, models, and system prompts
- **Define workflows** that chain multiple agents together
- **Run agents/workflows** with any AI provider (Claude, OpenAI, Gemini, Ollama, etc.)
- **Test suites** for evaluating agent performance across providers
- **Provider comparison** for benchmarking responses
- **Dry-run support** for CI/schema testing

### 3. AI Bridge Plugins (5 bridges — 25+ tools)
- **bridge.claude**: Claude API integration with sync/async/background spawn modes
- **bridge.openai**: OpenAI-compatible API (also routes deepseek, qwen, kimi, grok, perplexity)
- **bridge.gemini**: Google Gemini integration
- **bridge.ollama**: Local LLM support via Ollama
- **bridge.firecrawl**: Web scraping and crawling for AI context

### 4. Database Operations (devtools.database — 8 tools)
- **Connect** to PostgreSQL, SQLite, and other databases
- **Query, inspect, create, alter, drop** tables, views, indexes, constraints
- **Import/export** data
- **PostgreSQL-specific** (pg_* tools): RLS, partitions, materialized views, pgvector, full-text search, replication, VACUUM, ANALYZE

### 5. Code Intelligence (engine.rag — 22 tools, Rust)
- **Tree-sitter parsing**: Parse files, extract symbols, get imports (14 language grammars)
- **Tantivy search**: Full-text code search, symbol search, directory indexing (.gitignore-aware)
- **AI memory**: Save/search memories, observations, project summaries, session tracking
- **Cosine similarity** vector search for semantic matching

### 6. Notes & Documentation (tools.notes — 8 tools, tools.docs — 10 tools)
- **Create, search, tag, pin notes** with markdown support
- **Generate, scan, index documentation** across the project
- **Doc tree navigation** and full-text doc search

### 7. API Testing & Collections (api_* — 16 tools)
- **Make API requests** (replaces curl)
- **Save/organize** requests into collections
- **Import/export OpenAPI specs**
- **WebSocket support** (connect, send, close)
- **Request history** and environment variables

### 8. Secrets & Environment Management (secret_* — 6 tools)
- **Securely store, retrieve, update, delete secrets**
- **Import .env files** without exposing values in logs
- **Account-scoped env vars** for different providers

### 9. Background Script Runner (log_* — 10 tools)
- **Run background processes** with managed output capture
- **Tail live logs**, check status, restart, kill processes
- **Search and filter logs** across sources

### 10. Git Operations (6 tools)
- **Quick commit** with auto-generated messages using user profile
- **Push, pull, branch, merge** with natural language mapping
- **Status summary** for quick overview

### 11. Sessions Management (tools.sessions — 6 tools)
- **Create AI chat sessions** with any configured provider
- **Send messages** with automatic budget checking and usage reporting
- **Pause, resume, delete sessions**

### 12. Workspace Management (tools.workspace — 8 tools)
- **Create, switch, manage workspaces** with folder associations
- **Global workspace registry** persisted across sessions

### 13. DevTools Suite (100+ tools across 13 plugins)
- **Terminal**: Create, resize, stream terminal sessions
- **File Explorer**: 17 tools for file operations
- **Git**: 20 tools for advanced git operations
- **Docker**: 10 tools for container management
- **SSH**: 7 tools for remote server access
- **Services**: 6 tools for service management
- **Debugger**: 9 tools for debugging
- **Test Runner**: 8 tools for running tests
- **Log Viewer**: 5 tools for log analysis
- **Components**: 6 tools for UI component management

### 14. AI Awareness (19 tools across 3 plugins)
- **Browser context**: 7 tools for web page understanding
- **Screenshot**: 6 tools for visual capture and analysis
- **Screen reader**: 6 tools for accessibility-aware content extraction

### 15. Marketplace & Packs (tools.marketplace — 15 tools + 5 prompts)
- **Install, remove, update packs** (bundled skills, agents, hooks)
- **Stack detection** (12 technology stacks auto-detected)
- **Pack recommendations** based on project technology
- **17 official packs** available

## 🏗️ Architecture Highlights

- **Single-process in-process router** for local IDE use (fast, no network overhead)
- **TCP server** for desktop apps (Swift/Windows/Linux) on port 50101
- **QUIC + mTLS + Protobuf** for remote/engine connections
- **Plugin system**: 4 core bundled + 35 optional installable plugins
- **Multi-platform**: Claude Code, Cursor, VS Code/Copilot, Cline, Windsurf, Codex, Gemini, Zed, Continue.dev

## 📱 Desktop & Mobile Apps

- **macOS/iOS**: Swift universal app (menu bar + floating bubble)
- **Windows**: C# / WinUI 3 app (planned)
- **Linux**: Vala + GTK4/libadwaita (planned)
- **Mobile**: React Native with WatermelonDB (planned)

## 🚀 Quick Start

```bash
# Install
curl -fsSL https://raw.githubusercontent.com/orchestra-mcp/framework/main/scripts/install.sh | bash

# Start MCP server
orchestra serve

# Initialize a project
orchestra init

# Install packs
orchestra pack recommend
orchestra pack install orchestra-mcp/pack-essentials
```
